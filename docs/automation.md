# 每周整理提示词

在 Codex 中打开输出工作区（默认 `.runtime/workspace`），创建每周日 20:00 的自动化任务。工作区 `AGENTS.md` 已含本机 Python、工具与配置的绝对路径，直接按其中入口执行。启动器只生成工具和库；创建 Codex 自动化是独立的用户授权操作。

```text
检查并整理当前项目的本机 Obsidian 研究知识库。

先读本工作区 AGENTS.md、我的研究近况、导入覆盖报告与上次整理记录。执行 AGENTS.md 给出的 pipeline.py refresh 命令；不要同时运行另一份刷新程序。

读取 data/maintenance-latest.json 和对应 changes.jsonl。原研究文件只读；保留作者近况、手工笔记和历史摘录，不上传或推送私人资料，不改变登录或安装服务。

有新增或修改时，按项目选读最相关的来源，核对实际版本、原文存在性和提取缺口。概括新资料可能关联什么问题，指出有具体证据的冲突、局限及待确认事项。区分目录事实、文档陈述、系统推断、作者确认及已执行验证。不要从文件日期、计划或测试夹具推断研究完成。没有核对过的来源，不写成确定结论。

把解读另存为 研究知识库/03_我的笔记/自动整理/<日期时间>-本周理解.md，引用准确原路径及必要段落或页码；不要覆盖自动变化日志或此前笔记。

资料没有变化且没有可操作进展时保持安静；有重要变化、明确冲突、执行失败或需要我处理时才提醒。电脑和应用必须具备本次运行条件，权限不足时报告具体限制，不扩大访问范围。
```

Windows 自动索引任务仅生成变化记录；Codex 自动化还可以读取相关原文、回答并写解释。两者都不能在电脑关机时访问本机文件。原资料没有全部自动发给模型；Agent 选读片段的使用遵循产品当前数据设置。
