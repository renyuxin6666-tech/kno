# Documentation illustrations

`hero.svg` and `weekly-flow.svg` are original editable diagrams made for this project.

`workspace-redacted.png` and `map-redacted.png` start from native captures of a real local Obsidian workspace. They show an existing research-oriented vault, one use case of this general-purpose tool. Author markers, local source paths and private project labels were obscured using opaque mosaic edits with the built-in image generation tool. The image processing may resample visible pixels; these illustrations are not exact pixel comparison records.

The original captures and detailed editing prompts stay outside Git in the ignored local runtime. The published PNGs have no embedded text or EXIF metadata. They do not contain the original documents, extracted text catalog or private configuration. The numbers shown are facts from this one workspace, not a performance promise.
