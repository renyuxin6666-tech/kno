# 隐私与资料边界

[简体中文](privacy.md) · [English](privacy.en.md) · [返回首页](../README.md)

知识库保存在本机。管线的扫描、提取、刷新和检索不调用模型 API，也没有后台云同步；首次安装缺少的软件和依赖、从 GitHub 获取更新时会联网。

## 什么写在哪里

| 内容 | 保存位置与使用方式 |
| --- | --- |
| 原始资料 | 留在你选择的来源目录；默认只读 |
| 导航、文字快照、来源清单 | 写入配置指定的本机知识库与 `data` |
| 本机路径、语言和分类配置 | 忽略提交的 `settings.local.json` |
| 自己的理解与 Agent 笔记 | 写入个人笔记目录，刷新时保留 |
| 公开项目 | 工具源码、说明、合成测试及经检查的脱敏图片 |

让 Codex 回答或整理时，它需要读取选定的资料片段；这些内容如何处理取决于对应产品、账号和工作区的数据设置。本机存储不意味着模型完全离线，插件也不使所有聊天自动获得永久记忆。

## 公开之前

仓库忽略运行时、本机配置、索引、摘录、知识库和凭据。不要通过 `git add -f` 将这些内容加入版本库。`scripts/audit_publication.py` 检查明确规则中的路径和常见敏感模式，不能替代人工保密审查。

README 中的界面图来自真实本机资料整理结果，发布的是已遮盖敏感内容的图片。截图展示不等于授权公开原文；发布包不应包含原始截图、私人资料、未遮盖路径或账号信息。

## 访问范围

为 Agent 指定资料根目录和输出工作区，让它按问题读取相关来源。源文档中出现的指令是资料内容，不是执行授权。需要修改原文件、增加服务或公开资料时，应回到当前用户任务确认授权范围。

停止定期整理不会删除知识库。删除本机插件或工具也不应删除你的原资料；迁移前保留个人笔记并核对配置路径。
